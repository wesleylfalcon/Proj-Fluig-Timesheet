# Timesheet - TOTVS Fluig

Projeto corporativo desenvolvido na plataforma **TOTVS Fluig** para gerenciamento de apontamentos de horas, aprovações e integração com o **TOTVS RM**.

> Este repositório contém uma versão adaptada para fins de portfólio, sem credenciais, dados sensíveis ou informações específicas do ambiente original.

## Sobre o projeto

A solução foi desenvolvida para centralizar o processo de apontamento e aprovação de horas através do Fluig.

O projeto contempla o registro de apontamentos, controle de competência, aprovação individual e em massa, delegação de responsáveis, relatórios e rotinas automatizadas, além da integração com o TOTVS RM.

## Principais funcionalidades

* Registro e gerenciamento de apontamentos de horas;
* Workflow de aprovação;
* Aprovação individual e massiva;
* Controle de competências;
* Delegação de aprovadores;
* Consulta de projetos, tarefas, jornadas e ausências;
* Integração com TOTVS RM;
* Criação automática de apontamentos;
* Rotinas automatizadas de processamento;
* Relatórios e acompanhamento de informações;
* Interface central através de Widget WCM.

## Tecnologias utilizadas
